4 · The rules

Binding rules are never for sale

Binding

Break one and the portfolio is not allowed. No amount of return buys it back.

  • Exactly 3 holdings, equal weight
  • Chance of a big monthly loss at most 10 %. Loss size: 8 % / 5 % / 3 %

Checked exactly, not guessed.

Preferences

Weighed against each other in one score.

  • Higher return
  • Lower risk (weight 1 / 5 / 20)
  • Fewer changes (small switching cost)
  • Tech weight limit 100 % / 35 % / 20 %

The tech limit is a preference, by team decision.

5 · If everything sat in one score, enough return could “buy” a violation. Values are organiser assumptions.

Key design choice. The cardinality rule is built into the quantum circuit; the loss tolerance is an exact check after the choice, because a probability over scenarios is not a simple formula in the variables. The HiTec limit was binding at first and was changed to a preference by the team on 16 October; base verdicts did not change.
