# NotebookLM Resource Pack

This folder contains source material for creating a polished explanatory video
about the Quantum Finance project with NotebookLM or another professional
editor.

## Recommended upload order

1. `01_project_source_brief.md`
2. `02_narration_script.md`
3. `03_visual_storyboard.md`
4. `04_notebooklm_generation_prompt.md`

Also upload selected project evidence:

- `docs/decision_card.md`
- `docs/problem_formulation.md`
- `docs/findings.md`
- `docs/guide_plain_language.md`
- `README.md`
- `results/canonical/summary.json`
- `results/canonical/quantum_summary.csv`

For visuals, provide the figures from:

- `results/canonical/figures/fig_risk_return.*`
- `results/canonical/figures/fig_decision_map.*`
- `results/canonical/figures/fig_bootstrap.*`
- `results/canonical/figures/fig_qaoa_comparison.*`
- `results/canonical/figures/fig_holdout.*`
- `results/canonical/figures/fig_circuits.*`

## Intended output

- A professional 5–6 minute explainer video.
- Clear human narration with natural pauses and consistent volume.
- Real project figures and dashboard captures, not cartoon filler.
- Accessible explanations for a non-specialist audience.
- A serious, honest treatment of finance and quantum computing.

The source pack deliberately does **not** contain video-generation code or a
pre-generated video. It is editorial source material only.
